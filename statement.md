# Project Statement

## Problem Statement
Managing student records manually can make searching, updating, organizing, and evaluating academic information difficult. The project provides a simple command-line system for maintaining student records and generating basic performance information.

## Scope
The system supports student record creation, listing, searching, deletion, validation, file-based persistence, sorting, average calculation, and top-student identification. It is designed as a small academic project and can be extended with a database or GUI in the future.

## Target Users
- Students learning Java
- Faculty demonstrating basic student record management
- Evaluators testing Java programming concepts

## High-Level Features
1. Student record management
2. Search and deletion
3. Performance reporting
4. CSV file storage
5. Input validation and exception handling
6. Modular object-oriented implementation
